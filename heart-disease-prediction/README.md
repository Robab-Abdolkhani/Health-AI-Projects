# Heart Disease Prediction

This project uses a public heart disease dataset to build a basic predictive model in Python.

## Objective
To explore a healthcare dataset and develop a simple machine learning model for heart disease prediction.

## Tools
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Workflow
- Loaded and explored the dataset
- Checked for missing values
- Split data into training and test sets
- Built a logistic regression model
- Evaluated model accuracy

## Notes
This was a beginner machine learning project designed to develop practical skills in health data analysis.
