# Patient Segmentation using Clustering

This project applies unsupervised machine learning to identify patient groups in a heart disease dataset.

## Objective
To explore hidden patterns in patient data and identify clusters with different clinical characteristics.

## Methods
- Data preprocessing and scaling
- K-means clustering
- Elbow method to determine optimal clusters

## Results
Two patient groups were identified with distinct profiles in terms of age, cholesterol, and clinical indicators.

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Google Colab
