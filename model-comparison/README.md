# Model Comparison in Healthcare AI

## Overview
This project compares multiple machine learning models for predicting heart disease.

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest

## Objective
To evaluate model performance and understand trade-offs between accuracy and interpretability.

## Results
Random Forest and Decision Tree equally achieved the highest accuracy, while Logistic Regression provided a balance between performance and interpretability.

## Key Insight
Model selection in healthcare should consider not only accuracy but also explainability and clinical trust.

## Tools
Python, Scikit-learn, Google Colab
