# AI Governance Assistant (GenAI)

This project uses a large language model to generate governance and risk assessment checklists for healthcare AI systems.

## Objective
To demonstrate how generative AI can support AI governance and risk evaluation.

## Features
- Input: AI system description
- Output: structured governance checklist

## Tools
- Python
- OpenAI API
- Google Colab

## Example Use Case
Generating a risk checklist for an AI model predicting hospital readmissions, and for cancer detection from medical images.
